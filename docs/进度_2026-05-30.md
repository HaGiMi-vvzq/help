## 今日修复 (20+ 项)

### 数据安全
- seed.py 不再删数据（检测已有用户跳过），初始数据只灌一次
- 数据库 WAL 模式 + 启动自动备份
- reset_db.py 需输入 YES 确认，销毁前再备份
- .gitignore 排除 app.db、备份、uploads

### 资料持久化 (关键修复)
- UserResponse schema 新增 `extra` 字段（修复校区/学院/专业/年级/性别/乡镇全部消失）
- ProfileUpdate 新增 `username` 可修改
- 新增年级（大一~大四）和性别（男/女）选择
- embedding 改为后台异步，保存从 ~10s 降至瞬间
- watch(campus/college) 加 restoring 标志位，防止异步 watch 覆盖恢复数据
- 新增 `POST /api/profile/extract-tags` AI标签提取端点
- 新增 `GET /api/profile/user/{id}` 用户查询端点

### 消息+通知
- 站内信通知：自发送消息显示发送者为"系统"
- 对话列表：排除自发消息，不再显示自己
- 联系TA跳转：MessagesView watch 加 `immediate: true`，路由带 `?needId=`
- 新增用户查名端点，对话窗口显示正确用户名
- needIdMap 记住每个对话的需求ID，切换对话不丢失
- handleSend 加错误提示，发送后刷新对话列表
- 未读消息标记、通知角标刷新

### Agent 系统
- 删除会话：自引用FK手动清理（update parent → delete 有序）
- 首次进入不再自动创建新会话（有历史则跳最近，无则显示空状态）
- 文件上传：加 ElMessage 提示（成功/失败/加载中）
- .docx 文件解析（python-docx）

### Debug
- 全局 debug 事件面板（右下角，记录登录/注册/保存/API请求/错误）
- debug store 可在任何组件中调用 `debug.success()` / `debug.error()` 等

### 其他
- ElTag type 修复（技能交换=warning, 求助=danger）
- 需求卡片显示发起人姓名
- 匹配结果权限控制（非创建者403）
- MatchResult 类型补充 bio/extra
- CORS 支持 5173+5174
- api client baseURL 改为相对路径 `/api` 走 Vite proxy
- 级联删除 agent 数据（手动清理父子任务+消息+文件）
