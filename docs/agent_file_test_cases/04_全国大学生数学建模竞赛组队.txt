赛事名称：全国大学生数学建模竞赛

项目目标：
组建一个三人队伍，参加今年的数学建模竞赛。希望队伍分工明确，可以在比赛期间快速完成建模、编程、论文写作和排版。

现有成员：
1. 我负责论文写作和资料整理，能使用 Word、LaTeX，有一些科技论文写作经验。
2. 另一位同学会 Python 数据处理，做过可视化和简单机器学习。

缺少成员：
想找一名建模能力强的同学，最好熟悉优化模型、统计模型、评价模型或仿真模型。能在比赛中把问题抽象成数学模型，并和编程同学协作实现。

合作要求：
1. 比赛三天能够保证时间投入。
2. 赛前愿意一起看往年优秀论文。
3. 沟通及时，能接受快速迭代。

备注：
如果有同学虽然不擅长建模，但很会论文排版或图表美化，也可以联系。
