目前已有：
1. 初步调研问卷。

3. 两名成员，分别负责调研和材料撰写。

需要招募：

3. 有公益实践、校园社团或志愿服务经验的同学也欢迎。

项目周期：
预计 4 到 6 周，前两周做调研，中间做方案和原型，最后完成申报书和答辩材料。
