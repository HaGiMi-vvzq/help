### 2. 新功能: AI 辅助需求写作

- **AI 润色**: 用户写完描述后点"AI润色"，DeepSeek 结合用户画像优化表达，预览后可接受/重试/修改
- **AI 生成**: 只填标题点"AI生成描述"，自动生成完整需求描述
- **自进化学习**: `build_user_context()` 收集技能标签、偏好向量(反思结果)、历史需求风格、行为统计，每次润色/生成都注入个性化上下文

### 3. 新功能: AI 追问对话框

- 匹配结果页"AI 追问细化"按钮 → 弹窗式聊天界面
- AI 可读取匹配结果 + 候选人院系专业信息，针对性提问
- 隐私保护: 院系/技能等公开信息可答，手机/姓名等拒绝

### 4. 新功能: 需求管理 + 选择模式

- **单选/多选**: 发布需求时选择匹配方式
- **需求管理页** `/needs/manage`: 查看/关闭/重开/删除自己的需求
- **匹配结果中选人**: 每个候选人有"选TA"/"已选择✓"按钮，单选模式下选人自动关闭需求

### 5. 新功能: 智能 Agent 系统 ⭐

完整实现了一套具备记忆、规划、父子协作的 Agent 系统：

**后端 (18 新文件)**:
- 4 张新表: agent_sessions, agent_messages, agent_tasks, agent_files
- 8 个 Skills: tag_extraction, embedding, vector_match, explain, moderate, **file_reader**, **task_planner**, **context_summarizer**
- 5 个 Agents: PlannerAgent(父), FileReaderAgent, IntentAnalyzerAgent, NeedCreatorAgent, MatchWatcherAgent
- 3 个 Services: agent_service(CRUD), agent_memory(记忆管理+压缩), agent_planner(执行编排)
- 12 个 API 端点: 会话管理、对话、文件上传、规划、确认发布、知识检索、主动建议、起草消息
- 记忆系统: 4层(会话/存档/用户/知识)，超20条自动LLM摘要压缩

**前端 (3 新文件)**:
- `AgentView.vue`: 三栏布局(会话列表+聊天区+任务面板)
- 支持上传 .txt/.docx/.pdf，LLM 自动提取关键信息并建议发布需求
- 支持 `/plan 目标` 命令触发任务规划
