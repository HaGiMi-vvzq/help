# 项目简介

**校园AI互助匹配平台** 是一款面向高校学生的智能互助匹配工具。用户用自然语言描述自己擅长的技能（如"我会Python爬虫、做过Vue项目"），AI自动提取标签并生成语义画像。当有人发布求助或组队需求时，系统通过Embedding向量检索 + LLM精排，智能匹配最合适的伙伴，并生成可解释的推荐理由（如"张三的技能重合度94%，上学期刚完成类似项目"）。平台覆盖课程求助、比赛组队、技能交换三大场景，采用Vue 3 + FastAPI + DeepSeek技术栈，两天内可完成MVP演示。，并且在将来可以推广到更广的场景应用中去，如职场社交、兴趣社群等。通过智能匹配和个性化推荐，校园AI互助匹配平台旨在促进学生之间的交流与合作，提升学习效率和项目质量。
