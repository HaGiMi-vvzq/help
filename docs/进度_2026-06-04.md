## 部署方式

**开发环境**:
```bash
cd backend && python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
cd frontend && npx vite --port 5174
```

**生产环境**:
```bash
cp .env.prod .env
# 编辑 .env: SECRET_KEY, DB_PASSWORD, DEEPSEEK_API_KEY, DOMAIN, LETSENCRYPT_EMAIL
docker compose up -d

# 创建管理员
docker exec -it campus-backend python set_admin.py <用户名>

# 首次获取 HTTPS 证书
docker compose run --rm certbot certonly --webroot --webroot-path=/var/www/certbot -d $DOMAIN
```
